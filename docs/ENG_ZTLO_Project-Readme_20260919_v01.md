# Zyra & The Light Orb (ZTLO) - Project Readme


**Goal:** A stealth-educational, touch-first puzzle game for a 6-year-old (Zyra) to develop critical thinking, problem-solving, and emotional intelligence.
**Aesthetic:** Modern Storybook, soft vector graphics, analogous pastel palettes with complementary highlights.


## Architecture Pipeline
- **Prototype (Current):** Next.js (React 19) PWA, CSS Grid layout, absolute positioning, Framer Motion. Zero canvas/WebGL to maximize iteration velocity and reduce touch-latency friction.
- **Target (V2):** Phaser 3 + React PWA + WebLLM (Offline SmolLM2 for Socratic AI companion).


## Educational Curriculum Matrix
- **STEM / Logic:** Sequential switches (AND/OR gates).
- **Physics:** Friction, mass, optics (bouncing light).
- **Psychology:** Emotion regulation via NPC "mood auras" and empathy mapping.
- **Sociology/Philosophy:** Resource stewardship, trade interdependency.
